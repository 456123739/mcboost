# 下载编译好的 DLL

## Release（推荐）

**https://github.com/456123739/mcboost/releases/latest**

直接下 `PclHook` 相关的 4 个文件：

| 文件 | 大小 | 作用 |
|---|---|---|
| `PclHookInjector.exe` | 158 KB | 注入器 |
| `PclHook.dll` | 10 KB | 补丁本体 |
| `0Harmony.dll` | 2.2 MB | Harmony 运行时（**必需**） |
| `使用说明.txt` | 2 KB | 用法与排错 |

## Actions Artifacts（每次推送的构建）

**https://github.com/456123739/mcboost/actions** → 最新成功运行 → Artifacts 里下 `PclHook`

Artifacts 30 天后过期，只适合临时取用；要长期分享请用 Release。

## 本地重新构建

有 .NET 10 SDK 的话：

```bash
dotnet build pcl-hook/PclHook/PclHook.csproj -c Release -o out/hook
dotnet build pcl-hook/Injector/PclHookInjector.csproj -c Release -o out/injector
```

然后把 `out/hook/PclHook.dll`、`0Harmony.dll`（NuGet 缓存 `~/.nuget/packages/lib.harmony/` 里）、
`out/injector/PclHookInjector.exe` 三个文件放一起即可。

## 发新版

```bash
git tag -a v0.2.0 -m "说明"
git push origin v0.2.0
gh release create v0.2.0 --title "..." --notes-file notes.md \
  pcl-hook/dist/PclHookInjector.exe pcl-hook/dist/PclHook.dll \
  pcl-hook/dist/0Harmony.dll pcl-hook/dist/PclHook.deps.json pcl-hook/dist/使用说明.txt
```

（workflow 已配好 `release: published` 触发，会自动构建并附加资产）

取用步骤：
1. 打开上面的链接，点最新的成功运行（绿色 ✓）
2. 页面底部 "Artifacts" 区下载 `PclHook`
3. 解压得到：
   - `PclHookInjector.exe`  注入器
   - `PclHook.dll`          补丁本体
   - `0Harmony.dll`         Harmony 运行时（必需）
   - `使用说明.txt`

本仓库的 `dist/` 目录也保留了一份当前构建的快照，可直接使用。

## 本地重新构建

本机没有 .NET SDK 时，用 GitHub Actions 构建即可（推送即触发）。
有 SDK 的话：

```bash
dotnet build pcl-hook/PclHook/PclHook.csproj -c Release -o out/hook
dotnet build pcl-hook/Injector/PclHookInjector.csproj -c Release -o out/injector
```

然后把 `out/hook/PclHook.dll`、`0Harmony.dll`（NuGet 缓存里）、
`out/injector/PclHookInjector.exe` 三个文件放一起就是完整可用的。
